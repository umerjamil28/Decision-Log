# Decision Log

Small record of project decisions. Marketing page plus a demo you can type into.

```
npm i
npm run dev
```

Demo is at `/demo`. Nothing is saved on refresh.

For GitHub Pages, push `main` and turn on Pages via GitHub Actions. `base` is `./` so it also works in a project site.

See `notes.txt` for what I left out. `prompts.txt` is the raw AI prompts.
